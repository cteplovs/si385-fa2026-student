Course materials for SI 385. Everything you need is here or on Canvas.

## Start here

- **[docs/syllabus.md](docs/syllabus.md)** — how the course works, how you are
  graded, what is expected. Read this properly once; it is not boilerplate.

  20:59 the night before.

## Notebooks

`notebooks/lectures/` holds the in-class marimo notebooks, named by topic. They are
plain `.py` files — open them with `marimo edit <file>`, not Jupyter.

If your local environment is fighting you, use [molab](https://molab.marimo.io):
marimo's free cloud sandbox, no installation, runs in a browser tab. You will not be
locked out of an application exercise over a broken laptop.

## Data

Small files are committed under `data/`. Anything larger is fetched — see the notes
in the notebook that needs it.
